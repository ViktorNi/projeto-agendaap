Nome do projeto: Agendaap

Objetivo:
Criar um aplicativo de agendamento para profissionais que
trabalham com atendimentos e serviços, começando pela
necessidade real de uma profissional autônoma.

Primeiro caso de uso:
Minha mãe, que trabalha com cartomancia.

Problemas que o sistema pretende resolver:
- Esquecimento de horários agendados;
- Dois clientes marcados no mesmo horário;
- Cancelamentos de última hora;
- Dificuldade para manter a agenda organizada.

Objetivo inicial do MVP:
Permitir cadastrar clientes e organizar os atendimentos
em uma agenda, evitando conflitos de horário e fornecendo
lembretes dos próximos atendimentos.
